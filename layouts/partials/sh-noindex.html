{{- /* Returns true when a page should be kept out of the search index. Thin taxonomy terms are the reason this exists: a term page listing a single video is a weaker duplicate of that video's own page, and with ~300 of them they crowd out the real pages in both the sitemap and the crawl budget. Callers use this for BOTH the robots meta tag and the sitemap, so the two can never disagree. Excluded pages stay reachable and keep "follow", so they still pass link equity through to the videos they list. Covers: - pages that opt out explicitly (noindex = true in front matter) - taxonomy term pages listing fewer than two videos - taxonomy list pages with no terms at all (e.g. the unused categories) */ -}} {{- $noindex := false -}} {{- if .Params.noindex -}} {{- $noindex = true -}} {{- else if eq .Kind "term" -}} {{- $noindex = lt (len .Pages) 2 -}} {{- else if eq .Kind "taxonomy" -}} {{- $noindex = eq (len .Pages) 0 -}} {{- end -}} {{- return $noindex -}}
